# EducatEd Choice: A Data-Driven School Matching System

## Description
EducatEd Choice is a web-based, data-driven tool designed to help families make informed decisions when selecting public, private, or charter schools. The platform aggregates publicly available data from district and school websites, state education reports, and community forums, aligning with the mission of FYG Management LLC to empower families and communities through accessible technology. Using this data, the system generates a customized “best-fit” school report based on parent-provided profiles, including learning styles, academic and social needs, extracurricular interests, and preferred school environments. The prototype also incorporates structured parent feedback after school visits or enrollment to continuously improve future recommendations. This project provides hands-on experience in data integration, user-centered design, and web-based analytics while supporting a real-world educational initiative.
